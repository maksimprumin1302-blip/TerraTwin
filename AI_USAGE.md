# AI Usage and Provenance Disclosure — TerraTwin

**Project:** TerraTwin: Earth as a Space Laboratory  
**Public application:** https://terratwin-space.streamlit.app/  
**Repository:** https://github.com/maksimprumin1302-blip/TerraTwin  
**Disclosure date:** 2026-11-14  

## What AI helped create

OpenAI ChatGPT was used as a development assistant for parts of the Python implementation, debugging suggestions, interface copy and translation (English/Ukrainian), documentation, project descriptions, and presentation design. Some explanatory text and illustrative presentation assets were created or refined with AI assistance. The TerraTwin project submitters are responsible for inspecting, testing, editing, and submitting the work.

This project does **not** claim that NASA, ESA, or other scientific observations were generated by ChatGPT. The running app is a Python/Streamlit application using documented computational rules and external datasets; it is not an autonomous AI system performing new planetary measurements.

## Code: creation and metadata

Python source files in this distribution carry a short `AI DISCLOSURE` comment. The root `ai_provenance.json` file records AI-assisted development at project level. The files are maintained as project code; these comments are disclosure statements, **not** claims of independently audited software or scientific verification.

## Data: provenance and metadata

- **Scientific input data:** Earth observation and model datasets fetched from NASA POWER, Open-Meteo and other named third-party sources are produced by their respective providers. They are **not AI-generated observational measurements**. Provider models and estimates are labeled as such in the app.
- **`data/sites.json`:** a curated catalog of possible terrestrial analog locations and explanatory descriptions; compilation and drafting were AI-assisted. Site descriptions are educational summaries, not field measurements.
- **`data/feature_evidence.json`:** AI-assisted curation of qualitative feature annotations based on cited references. The feature labels and summaries should be checked against the linked scientific sources before being used for research decisions.
- **`DATA_SOURCES.csv`:** an AI-assisted catalog of source descriptions, data-access methods and limitations. The catalog itself is not an observational dataset.
- **Scores / proxies:** the 0–100 suitability scores and missing-data proxies are calculated by TerraTwin algorithms. They are **project-defined screening estimates**, not NASA-certified similarity percentages, validated landing predictions, or newly observed facts.

Machine-readable provenance for the local data assets is stored in `data/AI_PROVENANCE.json` and in root `ai_provenance.json`. Actual source records remain unchanged to preserve compatibility with the application.

## Presentation: images, video and audio

The competition demonstration and longer presentation were reviewed for disclosure. Decorative space and landscape imagery whose original creation history could not be independently established was **conservatively labeled `AI-GENERATED VISUAL`**. That marking avoids treating unverified artwork as an authenticated NASA photograph. Genuine screenshots of the TerraTwin interface remain identified as software screenshots, not AI-generated photographs. Slide decks and PDFs also contain AI-use information in document metadata.

No standalone AI-generated audio or video is included in the supplied submission package. If either is created later, the team should add disclosure to its description and metadata; video images generated with AI should display the appropriate visible label.

## Project limitations and transparency

TerraTwin analyzes selected Earth locations using mapped sources, gridded model products and explicitly labeled approximations. Missing evidence is not proof of absence. Earth testing scores should not be interpreted as measured Moon or Mars equivalence. Some external data services may be unavailable or provide incomplete coverage.
